# Keep README.md Up to Date

Whenever a phase, milestone, feature, or other meaningful piece of work is completed in this project, **automatically update `README.md`** before finishing the turn. Don't wait for the user to ask.

- Reflect new features, setup/run steps, env vars, tech stack changes, and project structure changes.
- Update any roadmap/phase/progress section (mark completed phases, add what's next).
- Keep edits concise and accurate; don't remove unrelated existing content.
- If the project is a git repo with a GitHub remote, commit the README change with the related work (e.g. `docs: update README for <phase>`) and push, unless the user has said not to push.
- Mention briefly in the final response that the README was updated.
